# Quant Interview Prep

A browser-based study desk for practicing questions from *A Practical Guide to Quantitative Finance Interviews*.

## Open the app

Clone or download this repository, then open **`Quant Interview Prep.html`** in a modern browser. Everything runs locally; no build step or account is required.

## Included

- 183 question-and-solution cards across six subject areas
- Chapter filters, full-text search, and random-question practice
- Hidden solutions, personal scratch notes, and self-ratings
- Session timing, progress tracking, and keyboard shortcuts
- Direct links from each card to the corresponding scanned source page
- Responsive desktop and mobile layouts

Progress, notes, and ratings are stored in the browser on the current device.

## Keyboard shortcuts

- `Space` — reveal the solution
- `J` / `K` — next / previous question
- `R` — random question
- `/` — focus search

## Source accuracy

The question bank was extracted from a scanned book. Formula-heavy cards can contain OCR imperfections; use **Open scan** on a card to verify the original notation.
